# Conference Room Booking API 🏢

REST API для управління бронюванням конференц-залів. Проєкт дозволяє створювати зали, шукати вільні приміщення на заданий час та оформлювати бронювання з автоматичним розрахунком вартості.

## 🚀 Основний функціонал
- **Управління залами (CRUD):** створення, редагування, видалення та перегляд списку залів.
- **Пошук вільних приміщень:** фільтрація за місткістю та відсутністю перетинів у часі з іншими бронюваннями.
- **Захист від подвійного бронювання:** валідація часових інтервалів при спробі забронювати зал.
- **Динамічне ціноутворення:**
    - 06:00 - 09:00: знижка 10%
    - 12:00 - 14:00: націнка 15%
    - 18:00 - 23:00: знижка 20%
- **Додаткові послуги:** можливість додати послуги (наприклад, проєктор, кава) до загального чеку.

## 🛠 Технології
- C# / .NET
- ASP.NET Core Web API
- Entity Framework Core
- SQLite (локальна база даних)
- Swagger (інтерфейс для тестування API)
